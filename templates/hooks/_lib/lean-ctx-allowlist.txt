# lean-ctx compression allow-list (v0.2.101) — the ONE committed rule table
# both lean-ctx-rewrite siblings PARSE (shared config, A>B>C tier B).
# Read by templates/hooks/lean-ctx-rewrite.sh (embedded python) and
# templates/hooks/lean-ctx-rewrite.ps1 (native PowerShell). Do not fork
# per-language copies of this list; edit it here once.
#
# RULE: a Bash tool call is compressed ONLY when it is a single simple
# command whose leading tokens match one entry below. Everything else runs
# RAW: loops, pipes, chains (&& ; |), redirects, command substitution,
# git (never allow-listed — owner rule), unknown commands, and anything
# matching a SEC-RAW credential pattern in the hooks.
#
# MATCHING: the command is whitespace-tokenized; leading VAR=value env
# assignments are skipped; the program token is reduced to its basename
# (so `.venv/bin/python -m pytest` matches `python -m pytest`); an entry
# matches when it equals the command's first len(entry) tokens (whole
# tokens, prefix-anchored: `npm install` matches `npm install foo` but
# not `npm` alone and not `npm uninstall`).
#
# Test runners and builds are safe to list ONLY because every compressed
# run is lossless: the lean-ctx-tee wrapper saves the full raw output
# under <project>/.claude/state/lean-ctx-tee/ and the compressed output
# ends with a pointer line naming that file.
