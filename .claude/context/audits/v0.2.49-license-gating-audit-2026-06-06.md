**Scope**: identify every GUI surface where a paid module's controls must be
gated on the orchestrator-tier license, and lock in the **grayed-out +
banner** treatment per the user's locked-in decision:

> "this but also show the tab grayed out with no ability to change config/update"

## Definitions

| Term | Meaning |
|---|---|
| **license_active** | `cache.orchestrator_tier !== 'free'` OR (server flipped to free with `last_error` mentioning `machine` — recovery path). Mirror of `hasActiveLicense()` from `$lib/admin-rebind`. |
| **license_missing** | No license key activated. `tier === 'free'` and no recovery condition. |
| **license_expired** | Key was activated, validate-tier now reports `tier === 'free'` with `last_error` set (any non-machine value: e.g. `expired`, `invalid_signature`, `revoked`). |
| **paid_module** | `m.license_required === true` OR `m.min_orchestrator_tier` is one of `'pro' \| 'mao' \| 'enterprise' \| 'admin'`. |
| **gated** | Treatment applied: controls visible but `opacity: 0.5`, `pointer-events: none`, `aria-disabled="true"`, native `disabled` attribute set. Banner at top of panel/tab. |

For the GUI's purposes, **license_missing** and **license_expired** receive
the SAME treatment (grayed-out + banner). The banner copy is slightly
different ("License required" vs "License expired") but the gating
behaviour is identical.

## Source-of-truth license state

The canonical source is `$lib/stores/license.ts` — `$license.cache`. This
is already used by `ModuleCatalog.svelte` (`tier = $derived($license.cache?.orchestrator_tier ?? 'free')`).
We will introduce a new helper module `$lib/license-gate.ts` exporting:

- `isLicenseActive(cache)` — mirror of `hasActiveLicense` from `admin-rebind.ts` but accepts the full TierCacheView.
- `licenseStatus(cache)` → `'active' | 'missing' | 'expired'` — derives expired vs missing from `cache.last_error` presence + `tier === 'free'`.
- `moduleNeedsLicense(entry)` — single source of truth for "is this module paid?".
- `moduleIsLicenseGated(entry, cache)` — composition: paid AND not active.
- `bannerCopy(status)` → object `{title, action}` for the banner header.

## Cross-OS considerations

CSS treatment uses:
- `opacity: 0.5` — universally supported.
- `pointer-events: none` — supported by WebKit / WebView2 / WebKitGTK.
- `aria-disabled="true"` — accessibility.
- Native `disabled` attribute on `<input>`/`<select>`/`<button>` — universal.

No platform-specific code paths. The gating works identically on
Linux/macOS/Windows webviews.

## Out of scope (other streams own these)

- Backend install gating (`install_module_for_project` Rust command) — Rust side already enforces `min_orchestrator_tier`. Not touched.
- Backend per-project enable toggle (Stream B's `module_set_enabled_for_project`) — Stream B owns the Rust command; we only gate the GUI surface.
- Server-side `min_orchestrator_tier` field shape in `module_catalog_client.rs` — already exists, not modified.
- Container runtime detection — Rust-side authoritative, no GUI changes.
