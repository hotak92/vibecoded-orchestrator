# transformers pinned <5 because CodeSage-Large-v2's `modeling_codesage.py`
# (loaded via trust_remote_code) calls the deprecated `init_weights()` and
# never calls `post_init()`. transformers v5 makes `post_init()` mandatory
# (it's where `all_tied_weights_keys` is initialised) and intentionally
# crashes if missing. Validated 2026-05-04: transformers 5.0.0 / 5.7.0 both
# fail with `AttributeError: 'CodeSageModel' object has no attribute
# 'all_tied_weights_keys'`. To unblock: open a PR on
# https://huggingface.co/codesage/codesage-large-v2 to call `post_init()`
# in `__init__`, OR migrate to a v5-native code-embedding model
# (Jina Code v3, Voyage Code 3, etc.). Tracking issue:
# https://github.com/huggingface/transformers/issues/43883 (closed —
# upstream confirmed this crash is by-design).
transformers>=4.40.0,<5.0.0
