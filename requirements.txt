# ─── Code embedding service (runs in container, but needed for CPU fallback) ───
# sentence-transformers (Apache 2.0)
sentence-transformers>=5.4.1
# transformers pinned <4.50 because CodeSage-Large-v2's
# `modeling_codesage.py` (loaded via trust_remote_code) has TWO
# distinct incompatibilities with newer transformers:
#
#   1. v5+: calls the deprecated `init_weights()` and never calls
#      `post_init()`. v5 makes `post_init()` mandatory (it's where
#      `all_tied_weights_keys` is initialised) and intentionally
#      crashes if missing. Validated 2026-05-04: 5.0.0 / 5.7.0 both
#      fail with `AttributeError: 'CodeSageModel' object has no
#      attribute 'all_tied_weights_keys'`. Tracking:
#      https://github.com/huggingface/transformers/issues/43883
#      (closed — upstream confirmed by-design).
#
#   2. v4.50+: `Conv1D` was moved from `transformers.modeling_utils`
#      to `transformers.pytorch_utils`. CodeSage's modeling_codesage.py
#      line 11 does `from transformers.modeling_utils import Conv1D`
#      and fails with `ImportError: cannot import name 'Conv1D' from
#      'transformers.modeling_utils'`. Symptom: the
#      code_embedding_service container starts, sentence-transformers
#      tries to load CodeSage with trust_remote_code=True, the import
#      fails, FastAPI app exits → restart loop forever (RestartCount
#      grows unbounded). Validated 2026-05-16 against 4.57.6.
#
# To unblock either: open a PR on
# https://huggingface.co/codesage/codesage-large-v2 to (a) call
# `post_init()` in `__init__` AND (b) import Conv1D from pytorch_utils
# with a fallback, OR migrate to a v5-native code-embedding model
# (Jina Code v3, Voyage Code 3, etc.).
#
# CVE-2026-4372 (GHSA-29pf-2h5f-8g72, RCE via attacker-controlled model
# config) is NOT reachable here: this service loads only the fixed,
# hard-coded CodeSage-Large-v2, never user- or remote-supplied model IDs.
# GitHub closed the Dependabot alerts on 2026-07-07. Do NOT bump past
# <4.50 to "fix" the CVE — that breaks the container (see above). The
# only sanctioned lift path is a deliberate embedder refresh (model
# swap), not a pin bump.
transformers>=4.40.0,<4.50.0
